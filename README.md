# 🎓 OFPPT Formation Continue

> Application web dédiée à la gestion et à la présentation des formations continues de l’OFPPT.

---

## 📌 À propos du projet

**OFPPT Formation Continue** est une application web développée avec **Laravel** permettant de centraliser, présenter et gérer les informations relatives aux formations continues proposées par l’OFPPT.

L’objectif est de proposer une plateforme simple, moderne et intuitive facilitant la consultation des formations et la gestion des données.

---

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|------------|-------------|
| 🐘 PHP | Langage de programmation |
| 🔴 Laravel | Framework Backend |
| 🗄️ MySQL | Base de données |
| 🌐 HTML5 | Structure des pages |
| 🎨 CSS3 | Mise en forme |
| ⚡ JavaScript | Interactivité |
| 🅱️ Bootstrap | Interface responsive |

---

## ✨ Fonctionnalités

- 📚 Consultation des formations continues
- 🔎 Accès aux informations des formations
- 🗂️ Gestion des données
- 👤 Gestion des utilisateurs
- 📊 Gestion des informations liées aux formations
- 📱 Interface responsive
- 🖥️ Interface simple et intuitive
